# Synso v1 使用手册

> 版本 0.1.0 · Windows · 中英双语（跟随系统语言，可在设置中切换）

## 1. 安装与启动

本机（开发者机器）的两个入口：

| 方式 | 路径 |
|---|---|
| **免安装直接运行** | `C:\Users\admin\Desktop\Synso\target\release\synso-app.exe` |
| **安装包**（推荐，含快捷方式与卸载器） | `C:\Users\admin\Desktop\Synso\target\release\bundle\nsis\Synso_0.1.0_x64-setup.exe` |

> 相对仓库根目录即 `target\release\synso-app.exe` 与 `target\release\bundle\nsis\*.exe`；版本号升级后安装包文件名会变，认准 `*-setup.exe`。安装后可从开始菜单/桌面快捷方式启动。

- 安装版按向导完成安装（桌面/开始菜单快捷方式默认创建；卸载时会询问是否删除数据，默认保留）
- 开机自启动默认开启（首次向导中可一键关闭，之后在「设置」中随时改）
- 主窗口关闭按钮 = 最小化到系统托盘继续运行（索引保持最新、快捷键可用）；真正退出请用托盘图标右键 → 退出

## 2. 首次运行

首启向导四步：**语言 → 选择要索引的磁盘卷 → 排除规则 → 开机自启告知**，最后点「开始」进入首次全盘扫描。

- 扫描期间可以正常使用电脑；关闭窗口它会缩到托盘继续
- 全盘首次扫描约需数分钟（约 4000 文件/秒）；之后靠文件系统监听实时增量更新，无需重扫
- 排除规则每行一条 glob 模式，例如：
  ```
  node_modules
  *.tmp
  .git
  ```

## 3. 快速搜索（日常主入口）

按 **`Ctrl + ;`** 任意时刻唤起搜索框（再次按下或 `Esc` 隐藏）。

| 想找 | 输入 |
|---|---|
| 名字含"报告"的文件 | `报告` |
| 拼音首字母 | `bg`（命中所有"报告…"文件）|
| 拼音全拼 | `baogao` |
| 某类大文件 | `ext:pdf size:>10mb` |
| 限定目录 | `path:desktop` |
| 组合 | `报告 ext:docx path:docs size:>1mb` |

**键盘**：`↑ ↓` 选择 → `Enter` 用默认程序打开 → `Ctrl+Enter` 在资源管理器中定位 → `Esc` 关闭。

尺寸单位支持 `b / kb / mb / gb`（1024 进制），比较符 `> >= < <= =`，区间 `size:100-500mb`。

## 4. 查重（磁盘清理）

1. 切到「查重」标签 → 点**启动分析**（**查重不会自动运行**，每次都由你手动触发；已算过的哈希永久保存，只要文件的修改时间和大小没变，重新分析、甚至重新扫描都不会重算）
2. 分析完成显示所有内容重复的分组：每组体积、份数、浪费空间
3. 展开任意组，三种处理：
   - **保留最新** / **保留最旧**：一键保留组内最新（或最旧）的文件，其余删除
   - **手动勾选**要删除的文件
4. 确认框会显示将删除的**数量与总大小** → 确认后删除
5. **所有删除一律进入系统回收站**，随时可还原；每组至少保留一个文件，不允许全删

## 5. 容量地图（蛋糕塔）

- 径向"蛋糕塔"：中心是当前根目录，子目录一环环向外扩散；**弧长 = 空间占比**，目录环与子环之间的空弧就是该目录直属文件占的空间
- **磁盘驱动器一层显示物理使用率**：最内层环按磁盘真实容量构成——已索引目录 + 灰色「未索引」块（被排除规则挡掉的部分等）+ 灰色「剩余空间」块，目录条旁显示「已用 800.2 GB / 共 931 GB」，图中心显示盘符与「800.2 GB / 931 GB」。总览视图不加物理块，但悬停任一磁盘弧同样显示该盘已用/共。注意：把文件移入回收站不会改变磁盘已用空间——清空回收站后这里才会下降
- **点击**任意块下钻（它成为新的中心），顶部面包屑可返回任意层级
- **层数可调**（默认 10 层）：工具栏「− / +」增减；真实磁盘根目录有节点数护栏（2 万节点），超出的部分并入「(其他)」块，下钻即展开
- **对比模式**：左右两棵蛋糕塔各自独立下钻，适合对比两个目录
- 悬停显示目录体积与占上级百分比
- 想知道"什么在偷偷吃空间"，这是最快的答案

## 6. 设置

- **语言**：自动 / 中文 / English，即时切换
- **快捷键**：改成你喜欢的组合 → 应用（冲突会提示并保留原快捷键）
- **开机自启动**：开关即时生效
- **排除规则 / 索引卷**：修改后需点「重新扫描」生效
- **自定义扫描路径**（开发/测试用）：点「添加文件夹…」把任意文件夹设为扫描根，测试范围可控；只保留自定义路径（取消勾选所有磁盘）即为纯定点扫描。保存后立即生效，watcher 马上监听新路径；「重新扫描」按新范围重建索引。稳定后移除自定义路径、重新勾选磁盘即回到全盘索引

## 7. 托盘

右键托盘图标：打开主窗 / 快速搜索 / 重新全扫 / 设置 / 退出。扫描进行中退出会提示确认。

## 8. 安全与隐私

- **删除只进回收站**，全软件没有任何永久删除入口
- 除你的明确操作外，**Synso 绝不移动、修改、重命名任何文件**；卸载不留残留（数据可选保留）
- **完全本地运行**：无云上传、无遥测、无网络请求
- 日志仅本地：`%APPDATA%\com.synso.app\logs\synso.log`

## 9. 常见问题

| 现象 | 说明 |
|---|---|
| 扫描期间打开设置页显示加载中 | 正常：数据在扫描队列后，扫描结束后自动出现（窗口不会卡死）|
| 快捷键按了没反应 | 可能被其他软件占用（如 PowerToys），到设置里换一个 |
| 搜不到刚放进来的文件 | 增量监听通常秒级；若刚从 U 盘拷入大目录需几秒，仍无则重新扫描 |
| 想重建索引 | 设置 → 重新扫描（会按当前卷/排除规则重建）|
